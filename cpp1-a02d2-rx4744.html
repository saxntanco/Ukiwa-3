2. 試験前 ― ここを飛ばさない

このアンチョコは操作票・社内手順・現場責任者の判断に優先しない。 実設備では回路分離、トリップロック、CT/VT状態、系統状態を確認してから試験する。

  • 対象：CPP1-A02D2、5A、50Hzを確認
  • 制御電源銘板を確認：AC/DC100～220V共用品かDC24V品か
  • 現在整定 511～591、定格設定 901～904を写真/記録
  • 出力接点設定 800～8b0 と「自動復帰/自己保持」を確認
  • 外部トリップ回路をロック。X0～X7は実遮断器トリップ用に使わない
  • CT二次回路を開放しない
  • RX4744を保護接地し、出力OFFで結線
  • MPD-3有無、T-E試験点、系統電圧設定904を確認
  • 不要動作ロック E-01～E-03 の状態を確認
  • 試験前に「復帰すべき変更値」をメモする
CPPの不要動作ロック：
E-01～E-03に電圧あり＝「非連系」→ DS/RP/UF/OF/UPをロック、LED点灯。
E-01～E-03が無電圧＝「連系中」→ 項目591の時間経過後にロック解除。

三菱 p2–3, p30, p43–44, p78, p84。

4. RX4744 共通操作 ― 正式画面名で追う

RX4744の特徴： 電圧0～3相・電流0～3相は各相独立フローティング。Vは125/250V、Iは20A。I1/I0のみ400mA/5mA微小電流レンジあり。制御電源はDC +4～+112V、最大0.5A。

共通セット

1
動作モードキー → 試験目的に合うモードを選択 → 実行。
2
シフト＋トリップ設定 → 【トリップ設定】 → 入力形式「接点入力」／論理「a接点」。
3
シフト＋出力要素 → 【出力要素】 → 周波数モード・波形タイプ・レンジ・試験使用相を設定。
4
電圧／電流 → 【電圧／電流】 → 使用相をもう一度有効化して、定常/故障の振幅・位相を入力。
5
出力オン／オフ → 出力。急変試験なら動作指令で定常→故障。

目的別モード

目的おすすめ理由
動作値を手早く探すホールド急変の定常値をダイヤルで徐変NFの51リレー操作例そのもの。T1表示を見ながら上下できる。
動作値を自動取得通常スイープ定常→故障を自動スイープ。振幅/位相/周波数を選択可能。
動作時間ホールド急変 + インタバル内部故障急変→最初のTRIP入力まで計測。
位相境界通常スイープ（位相のみ）正方向＝遅れ、負方向＝進み。
UF/OF95試験動作/復帰周波数と動作/復帰時間を1回で測れる。
DS全相ロジックホールド急変複数V/Iを同時に定常→故障へ切替できる。

動作時間のRX設定テンプレ

動作モード：ホールド急変
TRIP：接点入力 / a接点
カウンタ：インタバル内部
PSW：オルタネート（または現場方針によりモーメンタリ）

6. DSの考え方 ― ここが核心

A相＝IA＋VBC　／　B相＝IB＋VCA　／　C相＝IC＋VAB

             ┌─ A相DS（IA, VBC） ─┐
             ├─ B相DS（IB, VCA） ─┼─ 2相ANDのOR ─ DS-UV ─ 不要動作ロックNOT ─ DS出力
             └─ C相DS（IC, VAB） ─┘
                 ↑ L要素/H要素
  • 通常運用では2相AND。1相だけ方向条件に入ってもDS全体は出力しない。
  • DS-TEST ONは単相試験用。入力した1相だけで判定できる。
  • L/HはOR。片方を試験するとき他方をLOCK。
  • メーカー特性試験ではDS-UV=NO USEとしてDS本体の精度を切り出す。
  • 至近端3相短絡でPT二次電圧がなくても方向判定できるよう、電圧メモリーを持つ。

三菱 p27–28, p32, p41, p83。

9. DS 全相試験 ― RX4744の多相出力を活かす

三菱 p83は「単相及び全相回路」と明記。RX はV/I各相独立フローティングで、多相同時出力が可能。

A. 本来の2相ANDロジック確認

CPP：
DS-TEST = OFF
試験しないL/H = LOCK
DS-UV = NO USE
不要動作ロック = 解除状態

期待：
1相だけDS条件成立 → DS全体は不動作
任意の2相DS条件成立 → DS全体は動作
3相DS条件成立 → DS全体は動作

これはメーカー内部ロジックの機能確認。単相の精度試験とは目的が違う。

B. 全相を0°感度点にそろえる配線案

根拠組合せ 下記は「三菱p83の端子組合せ」「VCA=-(VAB+VBC)」「RX各相フローティング」「RXの＋位相=遅れ」から組み立てたRX4744専用配線案。三菱/NFがCPP1-A02D2専用として描いた1枚図ではないため、出力OFFで結線し、印加前に電圧計/ベクトル表示で確認する。

【電圧：2出力で三相線間電圧を作る】

RX V1(+) ───── A14
RX V1(-) ─┬─── A15
           │
RX V2(+) ─┘
RX V2(-) ───── A13

設定：
V1 = VBC = 110V ∠0°
V2 = VCA = 110V ∠120°（遅れ）

CPP内部：
VAB = -(VBC + VCA)
    = 110V ∠240°

【電流：3出力】

RX I1 → IA A17→A18 = I_test ∠0°
RX I2 → IB A19→A20 = I_test ∠120°
RX I3 → IC A21→A22 = I_test ∠240°

すると各DSの相対角：
IA vs VBC = 0°
IB vs VCA = 0°
IC vs VAB = 0°
→ 3相とも最高感度角

重要：RXの「平衡三相」は基準相から120°/240°を自動設定できるので、I1=0°を基準にI1/I2/I3を作るのに便利。ただし電圧はCPPが線間2入力＋内部演算構成なので、RXの3LS/平衡三相画面をそのまま「端子A13/A14/A15へ3本」と読み替えない。

18. 故障したら何が起こるか

CPP内部異常

正常：
監視リレー励磁
RUN点灯
Y(b接点) 開
保護出力許可

内部異常 / 内蔵電源異常：
保護要素出力をロック
RUN消灯
Y(b接点) 閉
不良コード記録

監視異常を電源入切りで解除する場合も、メーカーは外部トリップロックを要求。

RX4744異常

電圧/電流アンプの過負荷、ピーク超過、温度異常などを保護機能が監視。急変でハングする場合は電源ラインの容量/インピーダンスも確認。出力できない場合は【出力要素】と【電圧/電流】の二重有効を確認。
