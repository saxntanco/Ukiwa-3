130秒でつかむ結論

いちばん大事なのは、機器名より先に「電流が一周して電源へ戻る輪」を見ること。

ケーブルにはIcが流れる芯線と接地された金属遮へい層の間に静電容量があるため。
リアクトルにはILが流れるIcと逆向きの無効電流を作り、トランス負担を小さくする。
A2は帰路に置かれる正常時のIcをA2へ通すことで、被試験物側の充電電流を確認する。
接地側であることと、そこから直接大地へ追加接続することは同じではない。
A2を迂回する帰路を作れば、Icが分流してA2は全体を測れない。

2まずR-1220K単体――A2はまだ出てこない

AC100V → IP-R2000（電圧調整・制御）→ R-1220K一次側 → 昇圧 → 高圧試験電圧

R-1220K取説上、トランス部は入力AC0～120V、出力AC0～12000V、巻線比1:100。10350Vは取説に示される試験電圧例であり、実際の試験電圧は対象設備・適用基準・メーカー手順による。IP-R2000は実機では計器部と電源部に分かれるが、ここでは電源・制御機能としてまとめ、端子を推定して描かない。

リアクトルを接続していない段階では、DR-1220MHのメーター部そのものがないため、A2は登場しない。ここを飛ばすと「なぜ最初からA2があるの？」となる。

3DR-1220MHを高圧側へ並列追加する

被試験ケーブルは容量性負荷C。DR-1220MHは、そのCと並列に接続して遅れ電流ILを流す。直列に入れてケーブル電流を止める機器ではない。

高圧母線 ─┬─ 被試験ケーブル C ─→ Ic（進み） └─ DR-1220MH L ─→ IL（遅れ）

Ic：ケーブル充電電流

ケーブルには試験電圧がそのまま印加されるため、Icは流れ続ける。

IL：リアクトル電流

Icと逆向きの無効電流を作り、トランスから見た無効電流を補償する。

禁止する言い方：「リアクトルが充電電流を消す」。
正しい言い方：「ILによって、トランスから見た無効電流を補償する。Icはケーブルに流れ続ける」。

5なぜ、ケーブルから大地へIcが流れる？

高圧ケーブルの主なコンデンサは、芯線と、接地された金属遮へい層の間にできる。

交流電圧が変化すると、絶縁体中の電界が変化し、芯線側と金属遮へい層側の表面電荷が交互に増減する。金属部分では電子が動くが、正常状態で電子が固体絶縁体や空気を突き抜けるわけではない。回路上は、この現象を変位電流としてコンデンサ電流Icで表す。

i = C × dv/dt 正弦波の実効値：Ic = 2πfCV C：静電容量[F]　f：周波数[Hz]　V：印加電圧[V]
別の現象：端末表面の汚損・湿潤による漏れ電流、誘電損、コロナ、部分放電、フラッシオーバは、理想的な充電電流とは分けて考える。空気が絶縁破壊した場合だけ、空気中を導電電流が流れる。

70端子・接地端子・アレスターを整理

0端子（ゼロ端子）

DRリアクトル巻線の低圧側。リアクトル電流ILが出てくる回路端子で、A1側アース端子と結ぶ共通点側になる。

接地端子 ⏚

大地へ確実に接続する保護接地側。DR取説ではA種接地へ接続するよう指定されている。

DRの0端子 ─┬─ A2電流計経路 ─┬─ DRの接地端子 → A種接地 └─ 保護用アレスター ─┘

DR-1220MH取扱説明書では、0端子－接地端子間に、絶縁破壊時などの異常電圧からメーター部を守るアレスターがある。通常時はA2経路で測定し、異常時の電位差をアレスターが制限する考え方。

重要な訂正：0端子と接地端子を短絡すること自体が、常に禁止されているわけではない。取説は0－接地間へ「メーター部、外部電流計、または短絡線等」のいずれかを接続し、開放状態にしないよう求めている。
ただし短絡線がA2と並列になれば、電流は短絡線側を通り、A2によるIc測定は成立しない。

複数リアクトルの接地は、回路上同じでも配線上同じとは限らない

取説図では高圧端子と0端子は渡り接続される一方、各リアクトルの接地端子はそれぞれ接地記号へ枝分かれして描かれている。手書き写真のように接地端子を端子間で順送りに渡り、最後の1本だけを大地へ落とす方式は、理想回路では同電位に見えても、実配線では同一とはいえない。

  • 途中の端子や渡り線が緩むと、その先の複数台がまとめて未接地になる。
  • 故障電流・アレスター放電電流が共通の渡り線を通る。
  • メーカー図が個別枝線を意図している可能性があり、写真だけでは許容結線と断定できない。
教材での描き方：共通の接地母線を一本描き、各機器の接地端子から個別に枝線を下ろす。0端子の共通線とは明確に分ける。

8端末未処理で、金属遮へい層も未接地なら？

ケーブルは「芯線－大地間の一つのコンデンサ」ではなく、浮いた遮へい層を挟む二つの静電容量になる。

高圧芯線 ─ C1（芯線－遮へい層）─ 浮いた金属遮へい層 │ C2（外被・空気・床等による浮遊容量） │ 大地

C1とC2が直列になったように振る舞い、遮へい層の対地電位は0Vに固定されない。簡略化すると、遮へい層電位は次の容量分圧で決まる。

Vshield ≈ V × C1 / (C1 + C2)
  • 浮遊容量による電流は流れ得る。完全に電流ゼロになるとは限らない。
  • 空気中を通常の電子が飛んでいるわけではない。外被・空気を誘電体とする変位電流として扱う。
  • 遮へい層が危険電位へ浮く可能性がある。触れてよい0V部分ではない。
  • 芯線－遮へい層間へ10350Vが正しく印加された保証がない。意図した耐圧試験として評価できない。
  • 未処理端では電界が集中し得る。ケーブル本体が健全でも、端部でコロナ・表面放電・フラッシオーバが起こる可能性がある。
現場判断：端末未処理・遮へい層未接地のまま印加するための手順として使わない。ケーブル形式、端末構造、遮へい層、非試験心の処理、メーカー指定試験方法を確認してから試験計画を決める。
