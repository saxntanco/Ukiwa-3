## 独立計算の確認例

いずれも送り側100/200V、22sq、片道80m、力率1、R=1.08Ω/km。単相3線の近似モデルでの値です。

| 負荷条件 | L1電流 | L2電流 | N電流 | L1–N末端 | L2–N末端 | L1–L2末端 |
|---|---:|---:|---:|---:|---:|---:|
| 左右各50A、200V負荷なし | 50A | 50A | 0A | 95.68V | 95.68V | 191.36V |
| L1側のみ50A | 50A | 0A | 50A | 91.36V | 104.32V | 195.68V |
| 200V負荷のみ50A | 50A | 50A | 0A | 95.68V | 95.68V | 191.36V |

初期入力例はCVT、L1=50A、L2=30A、力率不明、管内1回路、周囲40℃、片道80m、目標3%です。比較上のN電流上限は58.31A、データの揃う最小候補は100sqです。同条件で両側の力率を1と指定するとN電流20A、最小候補60sq、最大電圧変化2.2232%になります。力率不明の結果は実測値の断定ではありません。

## 計算の前提

通常運転の正弦波・遅れ負荷で、3導体の長さ・太さ・インピーダンスが同一、送り側の対中性線電圧が左右で等しいモデルです。全負荷を区間末端にまとめます。銅導体600V CV・CVD・CVT、50/60Hz、周囲温度はメーカー掲載の20〜50℃が対象です。

単3では、各100V負荷の複素電流をA・B、200V負荷をC、導体インピーダンスをZ、片道kmをℓとして以下の電圧方向成分を用います。

- L1–N：ℓ Re[Z(2A−B+C)]
- L2–N：ℓ Re[Z(2B−A+C)]
- L1–L2：ℓ Re[Z(A+B+2C)]
- 中性線：|A−B|

線電流入力ではA・Bを各線の合計電流、C=0とします。平衡入力では左右の電流・力率が同一と確認されていることを前提にN=0とします。不明力率は0〜90°の遅れ角を取り、電圧・電流それぞれの比較用範囲を求めます。各上限値が同時に発生するとは限りません。

メーカーの標準電圧降下近似式を、不平衡の節点電圧を考慮して拡張したものです。メーカー公表の不平衡計算機能や実設備の実測確認そのものではありません。R・Xは導体温度90℃の表の値を使用し、周囲温度による補正は許容電流だけに適用します。

**このツールだけで電線の最終採用を決める機能ではありません。** ブレーカ定格・保護特性、短絡耐量、始動、端子温度条件、高調波、進み力率、中性線の細線化・断線、上流の電圧変動は未判定です。定電力負荷の電圧低下時の電流増加も反復計算しません。途中分岐・並列ケーブル・地中・多条布設などは、別の条件設定・計算が必要です。

目標3%は比較用の初期値であり、一律の法令適合を意味しません。許容電流と電圧変化の2条件に限定した候補を提示します。CVT/CVD 8sqはR・Xの出典付きデータ未登録のため補間せず、最小候補の探索から除外します。

## テストの再実行

計算テストはNode.jsの標準機能だけで実行できます。

```sh
node --test tests/cable-size.test.mjs
```

DOMテストはNode.jsとjsdomが必要です。jsdomを通常のモジュール探索先にインストールした環境で実行します。

```sh
node --test tests/cable-size.test.mjs tests/cable-size.dom.test.mjs
```

実ブラウザのテストにはPlaywrightとChromiumが必要です。ローカルサーバーで公開したHTMLを検証します。このスクリプトの通過結果は今回の検証数には含めていません。

```sh
python -m http.server 8123 --bind 127.0.0.1
# 別ターミナルから実行
node tests/cable-size.browser.mjs
```
