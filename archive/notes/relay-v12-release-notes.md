# うきわメモ v12 リリースノート

## 目的
既存の高速な型式検索を維持したまま、「まず覚える4つ（OCR / DGR / OVGR / RPR）」の教育導線を追加。

## 主な変更
- 検索欄の下にコンパクトな「まず覚える4つ」2×2/4列カードを追加。
- `relay-basics.html` を新規追加。
- OCR：限時/瞬時、引外し方式、3端子OCRの一次資料確認状況を整理。
- DGR：Io+Vo、M-N（Vo拡張）、親機/子機という現場語の扱い、電流抑制タイプの確認状況を整理。
- OVGR：DGRとの違い、太陽光での位置付けを整理。
- RPR：国内基本表示を67Pとし、海外IEEE/ANSI系の32/32Rと区別。
- 既存の `ANSI xx` 一律バッジ表示を `器具No. xx` に変更。
- 型式詳細からOCR/DGR/OVGR/RPRの原理教材へ双方向リンク。
- 既存の絶縁監視試験教材 `insulation-monitoring-test.html` を同梱。

## 技術的に「未確認」とした事項
- 現場でいう「電流＋電流方式DGR」と、公式資料で確認できた「電流抑制タイプDGR」の具体的な対応関係・原理・代表型式。
- 「4端子OCR」の全メーカー共通定義。端子数だけではなく、個別型式の内部接続図と引外し方式を優先する。
