# 電界決闘 — CIRCUIT DUEL

電気をテーマにしたオリジナルのCPU対戦カードゲーム。通信・アカウント・外部素材・実行時ライブラリは不要です。イラストも独自SVGです。

## 開発
Node.js 20以降で、このディレクトリから実行します。

    npm install
    npm run typecheck
    npm run build
    npm test
    npm start

http://127.0.0.1:8784/ を開いてください。配布時は dist の中身を同じフォルダーに配置します。file:// ではなくHTTPサーバーで開いてください。

## 遊び方
- ライフ20、デッキ20枚（10種類各2枚）、初期手札3枚。先攻はランダム。
- 毎ターンエネルギー上限が1増え、全回復（最大8）。1枚ドロー。ただし先攻初回はドローなし。
- 手札を押して使用。スペルは対象を選んで確定。キャンセル／Escで取り消せます。
- ユニットを押し、攻撃先を選択。各ターン1回。速攻以外は召喚ターン攻撃不可。
- 守護を先に攻撃。スペルは守護を無視。戦闘ダメージは同時で、行動済みの敵も反撃します。
- 手札8枚、盤面5体。手札超過は破棄。山札切れのドローは1、2、3…の疲労ダメージ。
- 相手ライフ0で勝利。同時に両者0以下なら引き分け。
- ⓘでカード詳細、画面上部の?で全ルールを確認できます。

## 構成
src/cards.ts: 読み取り専用カード定義。
src/engine.ts: DOMから独立した状態遷移・合法手検証・同時ダメージ。
src/ai.ts: 相手の手札や山札順を見ない、公開情報ベースの探索CPU。
src/ui.ts: 対象選択、演出、操作ロック、タイマーの取消、再戦。
src/art.ts: オリジナルSVG。src/style.css: レスポンシブと動きを減らす設定への対応。

CPUは最善手を保証するものではありません。短い先読みと盤面評価を使います。セーブ機能はなく、再読み込みするとタイトルに戻ります。

## 検証
npm test は20件のルールテストを実行します。疲労、手札超過、守護、速攻、同時戦闘、対象制約、不正操作時の状態保持、CPUの非公開情報遮断、リーサル判断、4試合の自動完走を含みます。
