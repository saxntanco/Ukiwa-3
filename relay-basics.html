OCR

過電流継電器

Over Current Relay

器具No.
51
30秒で分かるCTで見た電流が大きすぎると判定し、外部の引外し回路へ命令を渡す。
一次主回路
→
CT → OCR
→
接点 / 引外し回路 → VCB
通常時：CT二次電流は整定値未満。OCRは非動作。
事故：一次電流が増え、CT二次電流も増える。
判定：限時要素は時間特性に従い、瞬時要素は設定条件を満たすと速く動作。
接点・出力：OCRのトリップ出力が外部回路を成立させる。
遮断：VCB側の引外し機構へ必要なエネルギーが与えられ、遮断器が開く。
復帰：リレー接点、動作表示、VCBの復帰条件は機種・回路ごとに確認。
故障時：CT回路、OCR本体、トリップ回路のどこが失われたかを分けて考える。
3端子・4端子は、まず「引外し方式」から考える
一次資料で確認できたことムサシインテックは公式に「3端子OCR」と「電流引外し式CB」の連動試験を同じ文脈で扱っています。オムロン現行K2OCも、K2OC-ACNを「変流器2次電流引きはずし」、K2OC-AVNを「電圧・無電圧・直流引きはずし」と明確に分けています。
端子数だけで決めない「4端子なら必ずこの内部回路」という全メーカー共通定義は、今回確認した一次資料だけでは固定できません。端子の名称・共通点・トリップ出力の分離は実機の内部接続図で確認します。

現場での考え方

端子数を暗記する前に、VCBを何で引き外す方式かを確認します。三菱電機は、OCR・GRには電流引外し方式と電圧引外し方式があり、VCBと保護リレーは同じ引外し方式で組み合わせると説明しています。

事故を見つける部分：CT → OCR VCBを開かせる部分： A. CT側の電流を利用する電流引外し B. 別のトリップ電源を使う電圧引外し C. コンデンサ引外し電源を使う構成（電圧引外し側）

つまり、「OCRが検出すること」と「VCBを開かせるエネルギー源」は別の話です。

限時51と瞬時50

OCRという箱の中に限時要素51と瞬時要素50を併せ持つ機種があります。たとえばオムロンK2OCは動作電流、動作時間に加えて瞬時電流整定を持っています。したがって「OCR＝51だけ」とは決めません。

よくある勘違い
× OCR自身がVCBを機械的に開く一般にはOCRの出力がトリップ回路へ命令を渡し、VCB側の引外し機構が動きます。

DGR

地絡方向継電器

Directional Ground Relay

器具No.
67G
30秒で分かる「地絡がある」だけでなく、基準量との位相関係から“動作すべき方向”かを判定する。
主回路 → ZCT → Io ┐ ├→ DGR → 方向判定 → 出力 系統 → ZPD/ZVT → Vo ┘
通常時：Io・Voは動作条件を満たさない。
地絡発生：ZCTが零相電流Io、ZPD/ZVT等が零相電圧Voを与える。
方向判定：大きさだけでなくIoとVo等の位相関係を確認。
接点：電流・電圧・位相・時限の条件を満たすと出力接点が動く。
遮断・警報：設備側の外部シーケンスに応じてVCB/PAS等のトリップや警報へつながる。
復帰：自動/手動復帰は型式・設定で確認。
故障時：Io入力、Vo入力、制御電源、共通信号を分けて診断する。
M・N端子って何？ — 三菱旧MELPRO-Aの具体例
✓ メーカー一次資料で確認MDG-A1 / A2 + MPD-3

三菱電機の公式FAQでは、MPD-3形ZVTに直接接続できるリレーは5台まで。6台以上の場合は、MPD-3につながっているリレーの「Vo拡張端子（M-N）」を利用し、そのM-Nからさらに20台まで接続できると明記されています。

MPD-3（Vo検出） ├─ MDG 1 ├─ MDG 2 ├─ MDG 3 ├─ MDG 4 └─ MDG 5 ── M-N（Vo拡張） ──→ 追加DGR群（最大20台：当該FAQの構成）
重要M・NはDGR一般に共通する“親子端子名”ではありません。上記は三菱MDG-A1/A2世代で公式確認できた具体例です。別メーカー・別世代では結線図を個別確認します。
「親機・子機」って何？

まずメーカー正式名称を探します。今回確認した三菱資料では、正式な説明は「Vo拡張端子（M-N）」です。「親機・子機」という語を聞いたときは、“Voの元へ直接つながる側と、拡張されたVoを受ける側の話か？”を図面で確認するのが安全です。

未確認を残す「親機」「子機」を全メーカー共通の正式分類として定義できる一次資料は、今回の調査では確認できていません。現場用語とメーカー用語を混ぜないようにします。

故障時に考える順

① Voの元になる検出器 → ② 直接接続側 → ③ M-N等の拡張線 → ④ 下流側リレー、の順に「どこまで同じ信号を共有しているか」を結線図で追います。

Vo＋Io以外に「電流＋電流」のDGRはある？
✓ 存在まで確認△ 原理・代表型式は調査中

ムサシインテックの公式試験器ページでは、特別高圧設備向けに「電流抑制タイプの地絡方向継電器」が存在することまでは確認できます。

一方で、「どの2つの電流を使うのか」「現場でいう“電流・電流タイプ”と同一概念なのか」「代表リレー型式は何か」は、今回のメーカー一次資料ではまだ確定していません。

したがって今は断定しない一般的な高圧受電用DGRのIo＋Vo方式と、電流抑制タイプを同じ回路として描きません。型式とメーカー資料が固まってから別教材にします。
VoとIo・位相をどう考える？

オムロンK2DGは、零相電流と零相電圧の整定に加えて動作位相整定を持つ現行DGRです。「Ioが大きい」だけではなく、VoとIoの関係が動作条件に入ります。最大感度角や動作領域は機種ごとに違うため、教材の概念図と実機の位相特性図を分けます。

よくある勘違い
× 地絡電流が大きければ必ずDGRが動くDGRは方向判定条件も持ちます。Vo入力断線、ZCT極性、ZPD/ZVT異常、共有信号断線などでは「何の情報を失ったか」を分けて考えます。

OVGR

地絡過電圧継電器

Over Voltage Ground Relay

器具No.
64
30秒で分かるZPD・EVT・GPT等から得る零相電圧 Vo が設定値を超えたかを見る。
系統 → ZPD / EVT / GPT 等 → Vo → OVGR → 接点 → 警報 / 遮断シーケンス
OVGR基本はVoの大きさを判定。
DGRIo＋Vo等から地絡の方向まで判定。
太陽光発電設備では何のため？

高圧の自家消費型太陽光でOVGRとRPRが一体化した製品は実際にあります。オムロンK2ZC-K2RVは公式にOVGR（64）＋RPR（67P）を自家消費型太陽光発電用として掲載しています。

ただし「太陽光＝必ずOVGR＋RPR」ではない逆潮流の可否、連系方式、PCS内蔵保護、一般送配電事業者との協議条件で構成は変わります。売電/自家消費という言葉だけで外付けリレー構成を断定しません。
通常時 → 動作 → 復帰

通常時はVoが整定以下。地絡等によりVoが上昇し、整定値と時限条件を満たすと出力接点が動作。外部シーケンスにより警報・遮断へつながります。復帰方式は機種の自動/手動設定を確認します。

RPR

逆電力継電器

Reverse Power Relay

国内基本表示
67P
30秒で分かる電流の向きだけでなく、電圧・電流・位相から有効電力の方向を判断する。
電圧入力
＋
電流入力・位相
→
有効電力の方向 → RPR
通常時：受電点の有効電力方向が許容側。
逆方向の電力：発電量と負荷の関係などで、監視点の電力方向が反転。
判定：電圧・電流・位相から逆電力を算出し、整定値・時限を判定。
出力：RPR接点が外部の連系・遮断シーケンスへ命令を渡す。
復帰：逆電力が復帰条件を満たした後の接点復帰は型式仕様に従う。
67Pと32 / 32Rはどう整理する？
日本の現場表示国内メーカー製品ではRPRを67Pと表示する例があります。うきわメモの基本表示も67Pにします。
海外資料IEEE/ANSI系の資料ではReverse Powerに32/32Rを使う例があります。番号体系を混ぜず、別フィールドで扱います。

したがって「67P＝ANSI番号」とは書かず、国内器具番号67P / 海外IEEE・ANSI系32等と分けます。

太陽光：受電と逆潮流を絵で見る
発電量 ＜ 構内負荷電力会社 → 受電点 → 負荷
不足分を系統から受ける。
発電量 ＞ 構内負荷PCS → 受電点 → 系統側へ電力が向かう可能性。逆潮流を許す/許さない条件は設備ごとに確認。
電力会社 ─── 受電点 ─── 構内負荷 │ └──── PCS ← 太陽光

自家消費・逆潮流なしの保護構成では、受電点側へ逆方向の有効電力が出たことをRPRで検出する製品例があります。一方、逆潮流を許容する連系では「逆に流れたら即トリップ」という単純な説明は成立しません。

発電機でのRPR用途は？

RPRという保護要素の原理はここで扱いますが、発電機設備の運転・自動起動停止・切替シーケンスは別カテゴリです。
