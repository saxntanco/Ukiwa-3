# ぷかぷかうきわメモ 完成サイト v3

## 公開方法
1. このフォルダの中身をすべて GitHub リポジトリ `ukiwa` の直下へアップロードします。
2. ZIPファイルそのものをアップロードしても展開されません。必ずZIPを端末で解凍して、中身をアップロードしてください。
3. `index.html`、`tools`、`docs`、アイコン類を同じ階層に置きます。
4. GitHub Pages の公開元を `main / root` にします。

## 崩れ対策
- ホームページのCSS、JavaScript、主要画像は `index.html` 内へ埋め込んであります。
- 外部CSSや外部画像が読み込めなくても、ホームの見た目は崩れません。
- 記事、図鑑、マップ、安全ページは1つの `index.html` 内で動作します。
- 外部ファイルは交流耐圧試験シミュレータと参考PDF、PWAアイコンだけです。
