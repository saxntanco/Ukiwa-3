# うきわメモ

電気保安の学習・業務支援サイトです。

[公開サイト](https://saxntanco.github.io/Ukiwa-3/)

## ファイルの配置

- ルート：公開ページ、現在使うスクリプト・データ・画像。既存URLを維持しています。
- [archive](archive/README.md)：旧版データ、作業メモ、検証報告、プレビュー、旧配布パッケージ。
- [AGENTS.md](AGENTS.md)：サイト更新時の作業ルール。

2026年9月19日に、公開ページの内容・計算・リンク・配色を変更せず、管理用ファイルを整理しました。古い名前のHTMLも旧URLからの案内に使うため保持しています。

## 更新するとき

公開ファイルは元のパスで更新してください。試作や調査資料は archive 内の適切なフォルダーに保存し、ルートへ同名コピーを増やさないでください。公開ファイルの移動・削除は、参照元と直接アクセスへの影響を確認してから行います。
