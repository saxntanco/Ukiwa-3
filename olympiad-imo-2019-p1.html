関数方程式を
「代入」でほどく

国際数学オリンピック 2019年 第1問

解説作成：2026年10月23日（うきわメモ独自の解説）｜公式解答との照合：未

何を聞かれているか

整数を整数にうつす関数 f のうち、すべての整数 a, b で次の式が成り立つものをすべて求める問題です。

f(2a) + 2f(b) = f( f(a + b) )

正式な問題文は IMO公式サイトの過去問ページ（2019年）で確認できます。

まず自分で考える

ヒント1：どこから手をつける？

関数方程式の定番は「好きな値を代入する」こと。a = 0 や b = 0 を入れると何が残るか、2通り試してみよう。

ヒント2：右辺の f(f(…)) が厄介

右辺の f(f(x)) を、代入で得た式を使って f(x) だけの式に書き換えられないか考えてみよう。

ヒント3：ゴールの形

f(n+1) − f(n) が n によらず一定だと言えれば、f は一次関数 f(n) = mn + c に決まります。

答え

答えを見る

f(x) = 0　または　f(x) = 2x + c（c は任意の整数）

解説

解説を順に読む
1

a = 0 を代入。任意の b について

f(f(b)) = f(0) + 2f(b)　…①

右辺の厄介な f(f(…)) が、f 1回分の式に置き換えられるようになりました。

2

b = 0 を代入し、左辺の f(f(a)) に①を使うと

f(2a) + 2f(0) = f(0) + 2f(a)f(2a) = 2f(a) − f(0)　…②
3

元の式に戻る。左辺の f(2a) に②、右辺に①（b を a+b として）を使うと

2f(a) − f(0) + 2f(b) = f(0) + 2f(a + b)

2で割って整理すると

f(a + b) = f(a) + f(b) − f(0)　…③
4

③で b = 1 とすると

f(a + 1) − f(a) = f(1) − f(0)

差がいつも同じ値（これを m とおく）なので、c = f(0) として

f(n) = mn + c

正の方向にも負の方向にも同じ差で進むので、すべての整数で成り立ちます。

5

元の式に代入して m と c を決める。

左辺 = 2ma + c + 2(mb + c) = 2m(a + b) + 3c右辺 = m( m(a + b) + c ) + c = m²(a + b) + mc + c

すべての a, b で等しいので、係数と定数項をそれぞれ比べて

2m = m²　かつ　3c = mc + c

m = 0 なら 2c = 0 で c = 0、つまり f(x) = 0。
m = 2 なら 2c = 2c となり、c は何でもよい。

6

検算。f(x) = 2x + c のとき

左辺 = (4a + c) + 2(2b + c) = 4a + 4b + 3c右辺 = f(2a + 2b + c) = 4a + 4b + 2c + c = 4a + 4b + 3c

一致しました。f(x) = 0 は両辺とも0で明らかに成立します。

この問題で身につく型

  • 0を代入して「部品」を作る。①②のように、扱いにくい項を置き換える式を先に用意する。
  • 差が一定なら一次関数。整数上の関数は、隣どうしの差を見ると形が決まることが多い。
  • 最後は必ず元の式に戻す。「必要条件」で絞った候補が本当に条件を満たすか確かめる。

電気屋のひとこと

零点ずれのある計器と同じ形

③の f(a+b) = f(a) + f(b) − f(0) は「重ね合わせが成り立つ。ただし零点が f(0) だけずれている」という式です。零点誤差のある計器で2つの量を足して読むと、ずれが2回入るので1回分引く必要がある、のと同じ構造です。
