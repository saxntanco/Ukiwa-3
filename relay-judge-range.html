FIELD TOOL · 判定範囲

整定値を入れる。
試験電流と判定範囲が出る。

OCR・GR・DGRの単体試験で「何Aを流して、何秒〜何秒なら良か」をその場で計算します。測定値を入れると範囲内かも表示します。

基準：JIS C 4602（OCR）・JIS C 4601（GR）・JIS C 4609（DGR）の公開値。会社・団体独自の管理値は登録していません。メーカーが別の判定値を示す型式は、その値を優先してください。

OCR（過電流継電器）

計算のしかた（公式と許容差）

最小動作電流：限時は整定値の±10%、瞬時は±15%。

限時の動作時間：レバー10での公称動作時間 T に対して、300%で±17%、700%で±12%。レバー N で試験する場合は、JISの考え方 |t/T − N/10| ≤ 0.17（700%は0.12） から、範囲を T×N/10 ± 0.17T として計算しています。誤差幅は「レバー10の公称値」を基準にするので、レバーを下げても幅は狭くなりません。

公称動作時間の式（TMS = N/10、M = 整定値に対する倍率）

EI：t = 80 ÷ (M² − 1) × N/10
VI：t = 13.5 ÷ (M − 1) × N/10
NI：t = 0.14 ÷ (M^0.02 − 1) × N/10

誘導円板形などの旧形はこの式に乗らない機種が多いので、「手入力」を選んで銘板・取説の公称値を入れてください。

瞬時の動作時間：瞬時整定値の200%で0.05秒以下。

GR（地絡継電器・無方向）

計算のしかた

最小動作電流は整定値の±10%。動作時間は整定値の130%で0.1〜0.3秒、400%で0.1〜0.2秒（JIS C 4601）。

DGR（地絡方向継電器）

計算のしかた

最小動作電流：零相電圧を整定の150%で加え、整定値の±10%。最小動作電圧：零相電流を整定の150%で流し、整定値の±25%。

動作時間：Vo150%と、Io130%で0.1〜0.3秒、Io400%で0.1〜0.2秒。不動作試験：Vo150%・Io1000%・位相差180°で動作しないこと。位相特性はメーカーが示す範囲（JIS C 4609）。

完全地絡電圧は 系統電圧 ÷ √3（6.6kVなら約3,811V）。試験器のVo端子に加える電圧は、ZPD・継電器の定格によって換算が変わるので、取扱説明書で確認してください。

使うときの注意・出典

ここでの範囲は規格の一般値です。製造業者が型式ごとに別の判定値・試験条件を示している場合は、そちらに従ってください。公称値・許容差は「試験で良否を見るための値」で、保護協調の成立を保証するものではありません。
