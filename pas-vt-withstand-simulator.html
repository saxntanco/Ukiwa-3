VT内蔵PASの耐圧試験、
つなぎ方を間違えるとどうなる？

U・V・Wのどれに試験電圧をかけ、どれを接地・開放するか。つなぎ方を変えると、内蔵VTと他の相にかかる電圧がどう変わるかを計算します。

原理を理解するための教材
何を見ている？シミュレーター電流の流れEVTなぜそうなる？計算モデル根拠資料

相の呼び方は U・V・W にしています（R・S・T と書く資料もあります）。試験電圧は6,600V系の10,350V（最大使用電圧6,900V×1.5）、数値は二次開放相当の仮定モデルです。上位電源から切り離したPASを「入」にして負荷側ケーブルを含める模式図で、引用取説の「切」の指定とは条件が異なります。VTの特性も仮定で、実機の数値ではありません。実際の試験はPASの取扱説明書・社内手順・作業責任者の指示に従います。

そもそも、耐圧試験は何を見ている？

試験電圧を10分間かけても、絶縁が破れないかを確かめる試験。電流計に出る電流の大部分は、絶縁体を通る充電電流。

ケーブルの中の電流

高圧ケーブルは、導体と遮へい層が電極、絶縁体がそのあいだのコンデンサと同じ形です。遮へい層は接地されているので、試験電圧をかけると、電流は導体 → 絶縁体 → 遮へい層 → 遮へい接地線 → 大地 → 試験器、と一周します。

試験電圧

例：CV38mm²の1心・30m（1心の静電容量 約9.6nF）、50Hz。絶縁抵抗は健全 10,000MΩ・劣化 5MΩとした仮の値です。交流なので、実際の電流は1秒に100回（60Hzなら120回）向きが入れかわります。シース（外側のビニル）は電流の通り道ではないので描いていません。シースの絶縁は、遮へいの接地を外して絶縁抵抗計で測る別の試験で確かめます。

PASの中の電流

図は、上位電源から切り離したPASを「入」にして、電源側端子から負荷側ケーブルまで一緒に印加する仮定です。日本高圧電気の引用取説は設置後のケーブル込み試験で「切」を指定しています。実機の開閉状態と印加範囲は、この模式図から決めず対象取説・操作票で確定します。主要メーカーの取扱説明書では、内蔵VT（SOGの制御電源用）は負荷側のU相−V相の間に1台つながっています。

3相一括以外は、選んだ相に試験電圧をかけ、残りの相は開放（何もつながない）にしたときの図です。内蔵VTは U−V間に1台。

なぜ、開放したV相のほうへ電流が流れる？（U相だけのとき）

電流はU相にもV相にも流れる。U相のケーブルの電流（青）はVTを通らずに直接大地へ、V相のケーブルの電流（赤）はVTを通らないとたどり着けない。VTの巻線に負担をかけるのは赤のほう。2つの道は試験器に並列につながっていて、どちらも同時に流れる。

① 開放した電線も「コンデンサ」
V相は開放（何もつながない）でも、V相の心線と、まわりの遮へい層（接地）のあいだはコンデンサです。電線の電圧が変わるには、このコンデンサに電荷を出し入れする電流（充電電流）が必要です。

② V相へ電荷を運べる道は、VTの巻線だけ
試験器はV相に直接つながっていません。V相につながっているのは、U相とのあいだのVTの一次巻線だけです。だから、V相のコンデンサを充電する電流は 試験器 → U相 → VTの一次巻線 → V相 → V相ケーブルのC → 大地 → 試験器 と通るしかありません。このモデルのW相には対地容量だけがあり、相互容量と残留電荷を省いているため、定常計算では0V・電流なしです。実物の開放相が無電圧であることを保証する説明ではありません。

③ 二次開放を仮定したモデル：励磁LとV相のCが直列
ここでは二次開放を仮定し、VTの励磁インダクタンス L とV相ケーブルの静電容量 C の直列回路で考えます。二次短絡時は一次から見たインピーダンスが変わるため、この励磁Lだけの式をそのまま使えません。コイルとコンデンサは電圧の向きが逆なので、分かれ方は次のようになります。

VTにかかる電圧 ＝ 10,350V × XL ÷（XL − XC）
XL：VTの励磁リアクタンス、XC：V相ケーブルの容量リアクタンス ＝ 1 ÷（2πfC）

例：CV38mm²・30m なら C ≒ 9.6nF、XC ≒ 330kΩ（50Hz）。VTの XL を仮に 3.3MΩ（定格電圧で励磁電流2mA）とすると、
10,350 × 3.3 ÷（3.3 − 0.33）≒ 11,500V（定格6,600Vの約1.7倍。上のシミュレーターの値と同じ）
V相は試験電圧と逆向きに約1,150Vになり、VTには試験電圧より大きい電圧がかかります。

④ 過電圧や二次短絡で、過大な電流が流れるおそれ
二次開放でも、過電圧で鉄心が飽和すると励磁電流が増えるおそれがあります。飽和の始まる電圧や焼損までの時間は、励磁曲線・巻線抵抗・熱特性が未確認のため決められません。二次短絡時は、負担が一次側へ反映されることによる過電流も別に考えます。約31mAは「9.6nFのケーブル容量だけに10,350V・50Hzがかかる」とした I＝2πfCV の値です。直列L−C回路では容量にかかる電圧自体が変わるので、31mAを回路電流の上限にはできません。メーカーが一相ごとの耐電圧試験を禁止していることが、実機で守るべき条件です。

二次開放・一点接地・一括接地は、同じ？
異なります。二次開放では二次負荷電流が流れません。二次の一点接地は電位の基準を決め、健全な一次絶縁を通る直接の導通路は作りません。一方、二次両端を含む一括接地は二次短絡にもなるため、磁気結合を介して一次から見たインピーダンスや電流が変わります。「一次と二次が絶縁されている」ことは「二次の状態が一次に影響しない」ことではありません。

日本高圧電気の取扱説明書では、制御装置から制御線を外して端末を一括接地し、主回路を三相一括で試験します。三相一括なら相間VTの一次両端に電位差を作りません。二次の処置だけを変えて一相試験してよいという意味ではありません。

⑤ 交流なので、往復し続ける
電流は半周期ごとに向きが入れかわり、V相のコンデンサの充電と放電をくり返します。「一度流れて終わり」ではなく、試験のあいだずっとVTの巻線の中を往復します。

ケーブルがとても短い（Cが小さく XC が XL より大きい）ときは逆に、V相はU相に引っぱられて近い電圧になり、VTにかかる電圧は小さくなります（シミュレーターでケーブル長を0mにすると確かめられます）。XL の値はメーカー資料で確認できなかった仮の値です。V相だけ・V＋W短絡などのパターンも、「VTの片側だけに電圧がかかり、反対側の相のケーブルをVT経由で充電する」という同じ仕組みです。

図は原理を説明するための模式図で、実物の部品配置ではありません。メーカーにより、VTの台数・つなぐ相、ZCT・LAの有無と位置は異なります。お使いのPASの銘板と取扱説明書で確認してください。

計算モデルと仮定（数値を変えられます）

電圧は交流の実効値で、試験器の電圧を基準（0°）にした複素数で計算しています。VTは「励磁インダクタンス」と「損失ぶんの抵抗」の並列、各相は「ケーブルとPASの対地静電容量」で大地につながる、という線形モデルです。

鉄心の飽和・二次負担・二次短絡は計算に入っていません。定格との比較は表示しますが、飽和の開始点や焼損を判定する機能ではありません。ケーブル長によってはLとCが共振に近づき、大きな計算値が出ます。実機の非線形な励磁特性を用いていないため、鉄共振の発生条件や異常電圧の大きさを予測する値には使えません。

励磁電流・損失・PAS内部の静電容量は、メーカー資料で確認できなかったため仮の値です。値を変えると、異常電圧が出やすいケーブル長が変わります。「3相一括ならVTに電圧がかからない」「他相を接地するとVTに相間で試験電圧がかかる」という結論は、これらの値によりません。

VTを描いて、電流の流れを見る

焼損のおそれがあるのは、VTの一次巻線が「試験電圧から大地への通り道」の一部になってしまうとき。3相一括なら、電流は巻線の外側を回る。

図の見方：赤い動く線＝VTの巻線を通ってしまう電流、青い動く線＝ケーブルの充電電流（巻線の外を通る、正常な電流）。オレンジの線は試験電圧がかかっている部分です。

内蔵VT

図の「電線を接地」は、試験のときにその相の電線を大地につないだ状態（作業用接地の外し忘れ、1相ずつ試験するときの試験しない相など）です。VTの一次側には接地する点がありません。接地するのは二次側で、V結線なら2台の二次をつないだ共通端子にD種接地をします（電気設備技術基準の解釈 第28条）。PAS内蔵VTの二次側（制御線）は、試験のときは外して端末を一括接地します（取扱説明書の指定）。一点接地と二次両端の一括接地（短絡）は異なり、後者は一次から見たインピーダンス・電流にも影響します。上の計算モデルは二次開放相当です。

VT単体（単相VT 1台）

EVT（接地形計器用変圧器・Y結線）は、3相一括でも危ない

EVTは零相電圧を取り出すための計器用変圧器で、一次側はY結線、中性点を接地しています（10/4の日誌：電磁形EVTとコンデンサ形ZPD）。巻線が「相と相の間」ではなく「相と大地の間」につながっているので、三線短絡して3相一括にしても、各巻線に試験電圧がそのままかかります。

EVTの数値は、一次 6,600/√3 V・三次 190/3 V（オープンデルタで完全地絡時190V）の例で計算した目安です。切り離すか中性点の接地を外すかは、EVTと保護継電器の取扱説明書・社内手順に従います。

動きは電流の通り道を見せるためのもので、向きや速さは実際の交流を表していません（交流なので実際は向きが1秒に100回・120回入れかわります）。例の数字は、VT負担25VA（負担の一次換算電流は25/6,600 ≒ 3.8mA。励磁分を含む一次全電流とは別）、VT単体は巻数比60（6,600/110V）、PAS内蔵VTは6,600/105Vの二次開放時の換算例、CV38mm²・30m・50Hzの1相分の充電電流（約31mA）で計算した目安です。VT単体の正しい結線では、二次端子を短絡して外箱と一緒に接地します。PAS図の二次電圧は、一括接地（短絡）した二次側の電圧ではありません。実際の二次側の扱いは、PASの取扱説明書に従います。

なぜそうなる？

VTは相と相の間につながっている。VTの両端が同じ電圧なら、VTに電圧はかからない。3相一括なら、VTの電位差を作らずに3相の対地絶縁をまとめて試験できます。

内蔵VTは相と相の間：1台ならU−V間、2台ならV結線

PASの内蔵VTは、SOG制御装置の制御電源用です。主要メーカーの取扱説明書では、負荷側のU相−V相の間に1台つながっています（6,600/105V・25VA の例）。2台をV結線にする場合は、VT1がU−V間、VT2がV−W間です。どちらも、つながっている2つの相の電圧の差がそのまま一次巻線にかかります。

3相一括：3本が同じ電圧なのでVTは0V

U・V・Wを短絡して試験電圧をかけると、3本とも10,350Vで、VTの両端に差がありません。VTは励磁されず、試験されるのは3相とも「電路と大地の間」の絶縁だけになります。

他の相を接地：相間に試験電圧がそのままかかる

U相に10,350V、V相を接地すると、VT1の両端の差は10,350V。定格6,600Vの約1.57倍です。一次に定格を超える電圧がかかり、過熱・焼損のおそれがあります。飽和開始点や焼損までの時間はこの教材では特定しません。二次開放を仮定した巻数比の計算では約165Vになりますが、二次短絡時には同じ電圧にならず過電流が問題になります。

他の相を開放：電圧が決まらない（ケーブル次第）

二次開放相当の線形モデルでは、開放した相はVTの励磁インダクタンスと、その相の対地静電容量（ケーブル）の直列回路で電圧が決まります。二次負担・短絡・飽和がある実機には、下記の傾向をそのまま適用しません。

  • ケーブルがない・短い：開放した相はVTに引っぱられて試験電圧に近づく。条件によっては試験電圧より少し高くなる
  • ケーブルが長い：開放した相は大地側に引っぱられ、逆向きの電圧になることもある。VTに試験電圧以上がかかり、過励磁・焼損のおそれ
  • その間：インダクタンスと静電容量が共振に近づき、異常な電圧になりうる

「電圧バランスが崩れて、つないでいない相に思わぬ電圧がかかる」のはこのためです。

接地した相は、その回は試験されていない

1相ずつ・2相ずつのつなぎ方では、接地した相の対地絶縁は試験されていません。3相一括なら、3相とも一度に試験できます。

3相一括でも守れないもの：EVT・ZPD・LAなど

相と大地の間につながるものは、3相を短絡しても試験電圧がそのままかかります。

  • EVT（接地形計器用変圧器）：一次はY結線で中性点を接地。各巻線（定格 約3,810V）に10,350Vがかかり約2.7倍。三次のオープンデルタにも約520Vが出る。切り離すか、中性点の接地を外す（上の図）
  • ZPD（コンデンサ形の零相電圧検出器）：相と大地の間につながる。扱いは取扱説明書で確認
  • LA内蔵形のPAS：交流10,350Vの3相一括はできる。ただし AC12kV以上・DC17kV以上はかけられない（戸上電機）、直流耐電圧試験（DC20,700V）はLAが壊れるので行わない（日本高圧電気）

どれも、扱いは機器とPASの取扱説明書で確認します。

制御線とSOG制御装置の扱い

日本高圧電気の取扱説明書では、耐電圧試験のときは全ての制御線を外し、端末部を一括接地します。制御回路は一括と大地の間でAC2,000Vの試験です。戸上電機の取扱説明書では、SOG制御装置の各端子間の絶縁抵抗測定・耐電圧試験は行わないとしています。1相だけに試験電圧をかけると、VTの二次側の電圧が上がってSOG制御装置も焼損するおそれがあります。

VTの接地はどこ？「電線を接地」とは？

VTの一次側には接地する点がありません（相と相の間につながるだけ）。接地するのは二次側で、V結線なら2台の二次をつないだ共通端子にD種接地をします（電気設備技術基準の解釈 第28条）。

図の「接地」は、試験のときに電線を大地につないだ状態です。停電作業では、検電・放電のあと短絡接地器具で3相の電線を短絡接地します（労働安全衛生規則 第339条）。これを外し忘れたまま1相に試験電圧をかけると、「他相を接地」と同じ形になります。
