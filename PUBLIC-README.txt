うきわメモ CTツール公開用（既存サイトへの追加・上書き）

このZIPは、今回確認した「Ukiwa-3-main (1).zip」を元にした更新用です。
既存のうきわメモのファイルがある場所へ配置してください。
新しい空のサイトに、このZIPだけを配置する用途ではありません。

【GitHub Pagesで公開する場合】
1. このZIPをダウンロードし、解凍します。
2. うきわメモのリポジトリで、公開元の index.html があるフォルダを開きます。
3. Add file → Upload files を選び、下の6ファイルを追加します。
4. Commit changes で保存します。GitHub Pagesの公開処理が完了したら確認します。

ZIP自体ではなく、解凍後の6ファイルをアップロードしてください。
公開元が docs フォルダなら、その docs 内へ配置します。

【追加・上書きする6ファイル】
index.html                 トップにCT計算の入口・検索導線を追加
ocr-tap-calculator.html     OCRページにCTツールへのリンクを追加
ct-calculator.html         CT計算ページ
ct-calculator.css          表示用スタイル
ct-calculator.js           入力・結果表示
ct-core.js                 計算処理

すべて同じ階層へ置きます。既存の画像やほかのページは残してください。
この説明ファイルはアップロード不要です。
元ZIP以降にトップやOCRページを編集している場合は、その変更と統合してから上書きしてください。

【公開後の確認】
・トップの「08 CT比・電流計算」から開ける。
・トップ検索の「CT比」から開ける。
・「50/5Aの例」で一次30A → 二次3Aとなる。
・「単相＋三相の例」で最大線電流が約23.144Aとなる。
・入力を変えると古い計算結果が消える。

直接開く場合は、公開サイトの index.html と同じ場所の ct-calculator.html です。
表示が古い場合はページを再読み込みしてください。
