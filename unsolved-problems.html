数学

ミレニアム懸賞問題：2000年、アメリカのクレイ数学研究所が7つの難問に1問100万ドルをかけました。解けたのはポアンカレ予想だけで、ナビエ–ストークス方程式は2026年に「解決」が主張され、審査中です。
未解決ミレニアム懸賞問題

リーマン予想

ゼータ関数という関数の「意味のある零点」は、すべて一直線上に並んでいるか。

解けたら：素数がどう散らばっているかを、いちばん正確に見積もれるようになる。この予想を前提にした定理がたくさんある。

  • 最近2024年、ガスとメイナードが80年以上ぶりに、零点の数の見積もりを改良（2026年に論文掲載）。予想そのものの証明ではない
解決を主張・検証中ミレニアム懸賞問題

ナビエ–ストークス方程式

水や空気の流れを表す方程式で、なめらかな流れは、ずっとなめらかなままか。それとも、ある時刻に速さが無限大に「爆発」することがあるか。

解けたら：流体力学と乱流の、いちばん根っこの疑問に答えが出る。

  • 最近2026年9月、OpenAIが、外から力を加え続ける条件のもとで流れが爆発することをAIで証明したと発表。ほぼ同時に、ニューヨーク大学のバックマスターとAnthropicのアルペーゲも関連する結果を発表した
  • 状況クレイ研究所は「どうやら決着したようだ」としつつ、時間をかけて審査中。外から力を加えない場合は、まだ分かっていない
未解決ミレニアム懸賞問題

ヤン–ミルズ方程式と質量ギャップ

素粒子の力を表す理論で、「いちばん軽い粒子にも必ず質量がある」ことを、数学として厳密に示せるか。

解けたら：物理学者が実験で確かめて使っている理論に、数学の土台ができる。

未解決ミレニアム懸賞問題

ホッジ予想

複雑な図形のある種の「形の特徴」は、方程式で書ける図形の組み合わせで表せるか。

解けたら：図形を「形」から調べる方法と「式」から調べる方法が、深いところでつながる。

未解決ミレニアム懸賞問題

バーチ・スウィンナートン＝ダイアー予想

楕円曲線（y² = x³ + ax + b の形の曲線）の上に、分数の座標の点が無限にあるかどうかは、ある関数の振る舞いを見れば分かるか。

解けたら：「方程式に分数の解がいくつあるか」という古くからの問題に、強い道具ができる。

未解決

双子素数予想

11と13のように、差が2の素数の組は無限にあるか。

  • 最近2013年、張益唐が「差が7,000万未満の組は無限にある」と証明。その後の共同研究で、差の上限は246まで縮んだ（2014年）。2まではまだ遠い
未解決

ゴールドバッハ予想

2より大きい偶数は、すべて2つの素数の和で書けるか（例：10 = 3 + 7）。

  • 最近コンピュータでは 4×10¹⁸ まで確認済み。奇数版（弱いゴールドバッハ予想）は2013年に証明された
未解決

コラッツ予想

偶数なら2で割り、奇数なら3倍して1を足す。どんな数から始めても、最後は1にたどり着くか。

  • 最近2019年、テレンス・タオが「ほとんどすべての数で、かなり小さくなる」ことを証明。コンピュータでは約2⁷¹まで確認
  • 懸賞金日本の企業（バクアゲ）が2021年に1億2,000万円をかけた
未解決（論争中）

abc予想

a + b = c（共通の約数なし）のとき、c は「a・b・c に出てくる素数の積」より、めったに大きくならない。

  • 状況京都大学の望月新一が「宇宙際タイヒミュラー理論」で証明したとし、2021年に論文が掲載された。しかしショルツェとスティックスが重大な穴があると指摘し、数学界の多くは「未証明」と見ている。望月はコンピュータで証明を検証する計画を進めている

未解決ミレニアム懸賞問題

P≠NP予想

答えを「確かめる」のが速い問題は、答えを「見つける」のも速くできるか。

解けたら：もし「できる（P = NP）」なら、今の暗号の多くが破られ、最適化の問題が一気に解ける。多くの研究者は「できない（P≠NP）」と考えている。

手がかりあり

大規模な量子コンピュータは作れるか

量子ビットはとても壊れやすい。誤りを訂正しながら、役に立つ規模の計算を続けられるか。

  • 最近2024年、グーグルの「Willow」が、誤り訂正の規模を大きくするほど誤りが減ることを示した。2025年にはハーバード大学などが448個の原子で、誤りに強い計算機の基本要素を実証した
  • 状況実用に必要な誤りの少なさには、まだ大きな差がある
PHYSICS & UNIVERSE

物理・宇宙

手がかりあり

ダークマター（暗黒物質）の正体

銀河をつなぎとめている、目に見えない重さの正体は何か。宇宙の物質の大部分を占めると考えられている。

  • 最近米国のLZ実験は、2025年に世界最高の感度で探したが見つからなかった。2026年9月に「それらしい現象が1回」と報告したが、偶然の可能性も十分あり、発見とは言えない段階
手がかりあり

ダークエネルギーの正体

宇宙の膨張を加速させている「何か」は何か。

  • 最近2025年、DESIという観測が「ダークエネルギーは時間とともに弱まっているかもしれない」と報告。ただ2026年7月の新しい解析は、これまでの標準的な考え方と合う結果で、決着していない
未解決

ハッブル・テンション

宇宙が膨らむ速さ（ハッブル定数）が、測り方によって食い違う。初期宇宙の光から計算すると約67、近くの銀河から測ると約73（単位はkm/s/Mpc）。

  • 最近2026年の近くの宇宙をまとめた測定でも約73.5。一方で「食い違いは測定の問題では」という研究グループもある
未解決

物質と反物質の非対称

ビッグバンでは物質と反物質が同じだけできたはずなのに、なぜ物質だけが残ったのか。

  • 最近2025年、CERNのLHCb実験が、陽子の仲間（バリオン）で物質と反物質の振る舞いの違いを初めて観測。ただし、その大きさでは今の宇宙を説明しきれない
未解決

量子重力

重力（一般相対性理論）と、ミクロの世界の量子論を、一つの理論にまとめられるか。

  • 状況超弦理論などの候補はあるが、どれも実験で確かめられていない。必要な大きさ（約10⁻³⁵ m）は、実験で届く範囲をはるかに超えている
未解決

ニュートリノの質量

ニュートリノに質量があることは分かった（1998年、スーパーカミオカンデ）。では、本当の重さはいくつで、3種類の重さの順番はどうなっているか。

  • 最近2025年、ドイツのKATRIN実験が「0.45 eVより軽い」と報告。中国のJUNO実験が2025年に完成し、重さの順番を決めにいっている

生命の起源と「右手と左手」の謎

生命はどうやって始まったのか。なぜ生き物のアミノ酸は「左手型」ばかりなのか。

  • 最近2025年、小惑星ベンヌの試料からアミノ酸が見つかったが、右と左が半々だった

SOLVED

最近解けた問題（くらべるために）

解決

フェルマーの最終定理

3以上の n で、xⁿ + yⁿ = zⁿ を満たす正の整数はない。350年以上の難問を、ワイルズが1994年に証明（1995年に論文掲載）。

解決

ポアンカレ予想

ペレルマンが2002〜2003年に証明。フィールズ賞（2006年）もクレイの100万ドル（2010年）も辞退した。

解決

ケプラー予想

球をいちばんぎっしり詰める方法は、果物屋さんのみかんの積み方。ヘイルズが1998年にコンピュータを使って証明し、2014年にコンピュータで証明全体を検証し終えた。

解決

3次元の掛谷予想

あらゆる向きの針を入れられる図形の「次元」についての予想。2025年にワンとザールが3次元で証明し、ワンは2026年のフィールズ賞を受賞。4次元以上はまだ。

→ 賞の図鑑（フィールズ賞）

決着

ミューオンg−2の食い違い

ミューオンの磁石の強さが、理論と実験で食い違って見えた問題。2025年、実験の最終結果と、新しい計算方法を使った理論値が一致し、「新しい物理」の兆しではなかったことになった。

ほぼ解決

たんぱく質の形の予測

アミノ酸の並びから立体の形を当てる問題。AIのAlphaFoldが高い精度で予測できるようにし、2024年のノーベル化学賞になった。動き方や、形が決まらない部分などはまだ研究中。
